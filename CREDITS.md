# Credits

## Services Aurora talks to

Aurora is a client; it contains none of their code.

- **[OpenRouter](https://openrouter.ai)**, **[llama.cpp](https://github.com/ggml-org/llama.cpp)** and
  **[Ollama](https://ollama.com)**: the model backends it can use.
- **[Model Context Protocol](https://modelcontextprotocol.io)**: the standard its MCP servers follow.

Aurora is an independent project and is not affiliated with or endorsed by any of them.
